## Research question

Which concrete rules from Polar Orbit, shadcn CSS-in-JS, and Base UI should govern the project skills for creating constrained StyleX components and documenting them?

## Subtopics

1. Re-read Polar's LLM-safe design-system article for its constraints on tokens, component APIs, and styling escape hatches.
2. Inspect shadcn CSS-in-JS component structure for Base UI wrapping, StyleX file organization, and customization conventions without Tailwind.
3. Inspect Base UI's composition, customization, handbook, utilities, and LLM documentation for source-backed wrapper guidance.

## Synthesis

The findings will update the project-local component and documentation skills and the root `AGENTS.md`. The resulting rules will distinguish constrained product consumption from internal design-system implementation and will link agents to authoritative Base UI material.
