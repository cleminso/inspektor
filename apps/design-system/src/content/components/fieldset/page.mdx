## Usage

Use `Fieldset` to group related form controls. `Fieldset.Root` provides native grouping and can
disable every form control in the group. Add `Fieldset.Legend` when the group needs its own
accessible name.

Use [Text Field](/components/text-field) for a standard text input. Use [Field](/components/field)
to compose one field with a custom control or structure.
