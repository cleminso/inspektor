## Accounts table

Use TanStack column-pinning state to keep important columns visible during horizontal scrolling.
The Data Grid renders logical `start` and `end` regions with direction-aware sticky offsets.
Reorderable columns move only within their current pin region, and pinned moves update TanStack
column-pinning state without changing the column's unpinned order.
